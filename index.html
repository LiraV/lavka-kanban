МП → фронты → заявка → заведение → модерация → запуск → отчёты → финал

Новая задача

    ❓ Шпаргалка по процессу

    🧮 Медиаплан (МП)

    1. L1 · Новые запросы — принимаем запрос на расчёт МП, уточняем вводные (бюджет, период, гео, форматы).
    2. Расчёт МП — считаем план по бенчмаркам площадки.
    3. МП у фронтов — отправили фронтам, они общаются с заказчиком.
    4. Правки МП — фронты вернули с правками → пересчитываем → снова «МП у фронтов».
    5. МП согласован — ждём заявку на РК. МП может не дойти до запуска — тогда карточка через время уходит в «Завершено».

    🚀 Рекламная кампания (РК)

    1. Проверка заявки — фронты прислали заявку на заведение. Проверяем: брони, креативы, пиксели, тексты. Не хватает → «Заявка на доработке».
    2. Заведение РК — всё ок, заводим кампанию в кабинете площадки.
    3. Модерация — площадка проверяет. Не прошла → «Правки по модерации»: отправляем фронтам с комментариями площадки, после правок — снова заводим.
    4. Запуск · Скрины — РК запущена. Высылаем фронтам скрины: баннер на площадке, переход на посадочную, календарь (делаем сами или запрашиваем у площадки).
    5. Ведение · Отчёты — еженедельные отчёты: % выполнения, открутка, частота. При недокруте / высокой частоте — корректируем РК.
    6. Финальная статистика — по завершении высылаем финальный отчёт.

    📌 Полезное

    • Многомесячные РК: на каждый месяц — своя карточка РК. В карточке жми «📆 Копия на след. месяц».
    • Сплиты (бюджет разбит по гео / креативам / видам баннеров): на каждый сплит — своя карточка, связывай их одним кодом запроса. Жми «⧉ Дублировать».
    • Чек-листы: при перетаскивании карточки в новый этап нужный чек-лист добавляется автоматически. Кнопка «📅 Отчёты по неделям» создаёт пункты еженедельных отчётов на месяц карточки.
    • Специфичные площадки — не заводим сами, идём к старшим коллегам.
    • Данные хранятся только в этом браузере (localStorage). Делай «⬇️ Экспорт» для бэкапа.
