# 🥑 Канбан · Яндекс Лавка

Личная канбан-доска для ведения рекламных кампаний Яндекс Лавки (e-retail): от запроса на медиаплан до финальной статистики.

**Демо:** https://lirav.github.io/lavka-kanban/

## Процесс, зашитый в доску

**Медиаплан (МП):**
`L1 · Новые запросы` → `Расчёт МП` → `МП у фронтов` → (`Правки МП` ⇄) → `МП согласован`

**Рекламная кампания (РК)** — только после согласованного МП:
`Проверка заявки` (брони, креативы, пиксели, тексты) → (`Заявка на доработке` ⇄) → `Заведение РК` → `Модерация` → (`Правки по модерации` ⇄) → `Запуск · Скрины` (баннер, посадочная, календарь) → `Ведение · Отчёты` (еженедельно: % выполнения, открутка, частота) → `Финальная статистика` → `Завершено`

## Возможности

- 14 колонок под реальные этапы, сгруппированы в «Медиаплан» / «РК» / «Архив»
- Перетаскивание карточек, при входе в этап автоматически добавляется его чек-лист
- Кнопка **«📅 Отчёты по неделям»** — генерирует пункты еженедельных отчётов на месяц карточки
- **«📆 Копия на след. месяц»** — для многомесячных РК (новая карточка попадает в «Проверку заявки»)
- **«⧉ Дублировать»** + поле «Сплит» — для разбиения бюджета по гео / креативам / видам баннеров; карточки одного запроса связываются кодом запроса
- Площадки: Озон, WB, УрбанЭдс (Маркет, Лавка, Го, Еда)
- Дедлайны с подсветкой (просрочен / сегодня / скоро), приоритет 🔥
- Фильтры: поиск, тип, площадка, месяц, срочные
- Экспорт / импорт JSON-бэкапа
- Светлая и тёмная тема (по системной настройке)

## Данные

Все задачи хранятся **только в localStorage вашего браузера** — в репозиторий и на сервер ничего не отправляется. Для переноса на другой компьютер используйте «⋯ → Экспорт/Импорт».

## Запуск локально

Просто откройте `index.html` в браузере — сборка не нужна.
